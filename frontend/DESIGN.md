# 衡鉴造价库前端设计系统

来源：复用并适配 `../stitch_/precision_estimate_ledger/DESIGN.md` 与六个 Stitch 页面。该文件是后续 React 页面、组件与原型的视觉事实源。

## 视觉主题

专业、可靠、清晰的桌面数据工作台。界面服务于长时间、高密度的造价核查，不使用营销式首屏、装饰性图形或通用 AI 聊天布局。以表格、树形层级、筛选、来源抽屉和明确的确认操作为主要工作模型。

- 密度：高，默认桌面优先，主设计画布为 1440 × 900，兼顾 1280px 笔记本。
- 主框架：216px 左侧导航，52px 顶部全局栏，中心流式工作区。
- 数据工作区：筛选栏、表格、详情面板和右侧来源抽屉可组合，不以浮动卡片拼砌页面。
- 动效：仅用于抽屉、选中、加载和状态变化，150–200ms；遵循 `prefers-reduced-motion`。

## 色彩与语义

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 页面背景 | `#F3F4F6` | 工作区画布 |
| 工作表面 | `#FFFFFF` | 表格、表单、抽屉、弹窗 |
| 主文字 | `#191C1E` | 标题、正文、关键数据 |
| 次级文字 | `#3F4944` | 元数据、筛选标签、辅助描述 |
| 分割线 | `#BEC9C2` | 结构边界和表格横线 |
| 主操作绿 | `#00513B` | 主按钮、当前导航、历史原始值、确认完成 |
| 信息蓝 | `#004395` | 链接、系统计算值、信息提示 |
| 待确认琥珀 | `#804300` | 口径差异、待复核、风险提示 |
| 错误红 | `#BA1A1A` | 阻断错误、高风险或不可用 |

颜色从不独自表达状态。所有状态同时带有文字和图标。AI 建议、规则匹配、系统计算值和历史原始值必须使用明确的数据类型标签。

## 排版与数字

- UI 与中文正文：`PingFang SC`, `Microsoft YaHei`, `system-ui`。
- 金额、工程量、日期、编码：`JetBrains Mono` 优先，开启等宽数字。
- 页面标题：22px / 1.25 / 700；区块标题：16px / 700；正文：13–14px；表格与元数据：12px。
- 价格、数量一律右对齐；描述、项目名与来源一律左对齐。
- 不使用负字距、超大标题或全大写的正文。

## 组件规则

- 表格：固定表头，默认行高 36px，单元格横向内边距 12px，使用水平分割线；主数据页面优先表格，不使用卡片墙。
- 导航：当前项为浅绿底、深绿文字与右侧 3px 指示条；不做彩色图标墙。
- 按钮：主操作深绿填充；次操作白底边框；第三操作为文字按钮。高度 32px，圆角 3px。
- 标签：圆角最多 3px。历史原始值、系统计算值、规则匹配、AI 建议、用户确认值均为文本标签。
- 抽屉：右侧来源与证据抽屉默认宽 400px，保留主表上下文；复杂确认优先就地双栏或三栏，不滥用模态框。
- 表单：输入框高度 32px，标签在输入框上方；焦点为蓝色 2px 轮廓。
- 卡片：仅用于独立摘要、质量统计或明确的层级容器。圆角不超过 5px，无装饰性投影。

## 页面模式

- 数据查询：左侧结构化筛选，中部自然语言条件与高密度结果表，右侧来源抽屉。显示样本数、中位数、价格区间和可点击的分布辅助图。
- 项目库：筛选条 + 全宽项目表；项目状态、版本和指标就地可见。
- 导入质量复核：质量统计 + 异常列表 + 原件片段与系统解析对照。正常记录不抢占视觉优先级。
- 清单匹配：左侧清单树，中间候选列表，右侧证据与价格组成。候选必须解释相同点和不一致项。
- 价格对比：2–5 个样本摘要、对齐的费用组成表与可比性诊断；不使用雷达图。

## 可访问性与禁用项

- 基线为 WCAG 2.1 AA：清晰焦点态、语义化表格、完整键盘操作、状态不只依赖颜色。
- 支持系统缩放；桌面主工作流至少在 1280px 宽度可用。
- 禁止渐变、玻璃拟态、霓虹光晕、暗色科技大屏、大圆角、装饰插图、聊天机器人作为主界面、营销文案和假数据。
- 禁止将历史原始价、可比价和 AI 推断值混为同一个视觉层级。
