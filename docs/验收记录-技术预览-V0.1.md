# 技术预览验收记录 V0.1

## 已自动验证

- Alembic 初始迁移可升级、回滚和再次升级，FTS5 trigram 可创建。
- 定点数舍入、非有限值和 64 位溢出保护。
- 人工构造 Excel 的哈希归档、解析、复核、事务发布和重复导入拒绝。
- 清单项来源追溯、综合单价组成关联、全文检索、模糊候选匹配和三项指标。
- SQLite Online Backup、原始文件清单和 SHA-256 manifest。
- Host、写操作会话令牌和统一校验错误。
- React TypeScript 生产构建。

## 正式 V1 阻断项

真实兼容性和准确率尚未验收。正式 V1 前必须取得至少 5 个脱敏广联达项目，覆盖不同版本、专业、公式、合并表头和一个内地港式清单项目，并执行需求文档中的 99.5%、98%、100% 与 Top-5 90% 验收。
